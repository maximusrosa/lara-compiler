# lara-compiler

The project for the course INF01083 (Programming Languages ​​II) involves the incremental construction of a complete compiler for LARA (*Linguagem Acadêmica Reduzida e Adaptada*— Reduced and Adapted Academic Language), a small-scale imperative language.

The compiler is developed in four stages throughout the semester, with each stage adding a layer to the compilation pipeline:

- Stage 1: Frontend (scanner and parser)
- Stage 2: Intermediate backend (Three-Address Code generation)
- Stage 3: Intermediate backend (Three-Address Code optimization)
- Stage 4: Final backend (x86-64 assembly code generation)

The input is a program written in LARA. Stage 1 corresponds to the compiler's frontend, featuring a scanner generated by Flex and a parser generated by Bison, which produces an Abstract Syntax Tree (AST).

Stages 2 and 3 involve implementing an intermediate backend that generates abstract Three-Address Code (TAC).

Finally, Stage 4 corresponds to the implementation of a final backend that generates x86-64 assembly code, which can be compiled into an executable binary using GCC (`gcc -no-pie`).
